# Baron Bridge

Baron Bridgeは、オーディオアプリのステレオ出力をWASAPI共有モードでWindowsの再生デバイスへ送る仮想オーディオドライバーです。画面録画にシステム音声として演奏を含められます。

Baron Bridge is a virtual audio driver that routes stereo output from compatible audio applications to a Windows playback device through WASAPI shared mode, where screen recording software can capture it as system audio.

## ダウンロード / Download

[Baron Bridge 1.0.2 の配布ページ / Download Baron Bridge 1.0.2](https://github.com/baron-potato-audio/baron-bridge/releases/tag/v1.0.2)

Releasesから `Baron-Bridge-1.0.2-windows-x64-gplv3.zip` をダウンロードし、展開して `Baron-Bridge-x64-Setup.exe` を実行してください。Windows 10／11 x64と64ビット版のオーディオアプリに対応します。インストーラーの実行には管理者権限が必要です。

Download `Baron-Bridge-1.0.2-windows-x64-gplv3.zip` from Releases, extract it, and run `Baron-Bridge-x64-Setup.exe`. Requires Windows 10 or 11 x64, a compatible 64-bit audio application, and administrator rights to install.
